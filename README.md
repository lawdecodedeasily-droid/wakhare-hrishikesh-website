# Wakhare Hrishikesh — website

Astro static site, deployed on Vercel.

## Develop

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # outputs to dist/
npm run preview   # serve the production build locally
```

## Branches

- `main` — the live site.
- `redesign` — full rebuild in progress; see `REDESIGN-PROMPT.md` (gitignored, not in this repo listing) for the build spec, and `OPEN-QUESTIONS.md` (also gitignored) for the running list of items that need Hrishikesh's confirmation before launch.
